# Buddy2api v2.1.17

发布日期：2026-10-09

小版本：Codex 走 Responses 时不再把超长历史和提权审查原样撞上上游限制。管理页可以切换用量时间窗，也可以在现有暖色和黑金配色之间切换。

## Codex

- 保留 Responses `text.format` 里的 `json_schema` / `json_object`，转成 Chat `response_format`，并另加一条 JSON 约束。普通文本请求不改。
- 识别当前 Codex 提示。旧权限标记消失后，超长提示仍会换成短安全提示，避免上游 `11128`。
- `gpt-5.6-luna` 在 WorkBuddy 别名里转到 `deepseek-v4-flash`，自动提权审查可以落到已配置的模型。
- 只对 `client_type=codex` 的 `/v1/responses` 做预裁剪。估算超过 467,232 token 时丢掉更早历史，保留最新一轮，工具调用和结果一起丢。中文按一字一 token 计。其他客户端不裁。

## 管理页

- Dashboard 增加今日、昨日、七天、30 天用量。主趋势可以在柱状、折线和面积之间切换。
- 顶栏增加「黑金 / 暖色」按钮。黑金配色取自 lab-agent dashboard：近黑底、金色强调。选择记在本机浏览器，默认仍是暖色。

## 升级说明

- 无数据库迁移。
- 重启进程即可。Codex 预裁剪只对标记为 `codex` 的 API Key 生效。
- Docker 用户需要重新构建镜像并重启服务。
- 发版只改 `version.py`、README 和本说明；不要改 `web/index.html` 里的版本字符串。
